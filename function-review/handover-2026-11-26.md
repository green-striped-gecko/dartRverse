## What is new in dartR.base dev 1.3.2

- `gl.last.plot()`: returns the plot(s) of the last dartR function that made
  one, without plot.file. Kept by `utils.plot.keep()` in 32 `gl.*` functions;
  base-graphics plots (trees, heatmaps, shapes) are kept as recorded plots.
  A function that drew nothing clears the kept plot (no stale plot).
- `gl.plot.code()`: prints ggplot2 code that changes the kept plot. Titles set
  as scale names (e.g. gl.smearplot axes) are changed with `guides()`, because
  `labs()` cannot change them; suggested scales repeat the legend title and
  labels.
- Slimming (`R/utils.plot.keep.r`): a kept plot no longer holds the plotting
  function's working space (ggplot2 4.0 stores it via plot_env, aesthetics,
  ggproto `super` and the cached `computed_mapping`). Example, 100 ind x
  10,000 loci: gl.report.callrate 19 -> 5.7 MB (measured with ggplot2 4.0.0).
  If slimming fails, the plot is kept unslimmed and the reason is stored in
  `.dartR_plots$slim_error`.
- CI: tests run serially (`TESTTHAT_PARALLEL: false` in check-standard.yml;
  the ubuntu R-devel job was killed with exit 143 in parallel). Locally they
  still run in parallel (DESCRIPTION Config/testthat/parallel).
- FBM-examples workflow runs only on pull requests into dev and on manual
  start.
